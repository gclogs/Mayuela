# 플레이어 색상과 식별

## 문서 역할

플레이어 색상 배정, HEX 코드, 색깔 블록, 머리 위 식별 표시를 정의합니다.

## 색상 배정

플레이어가 `/입장`을 실행하면 즉시 색상이 정해지지 않고 `준비` 상태로 등록됩니다.  
팀 색상은 관리자가 수동으로 지정하거나, `/game 시작` 시 배정되지 않은 플레이어를 무작위로 2명씩 묶으면서 정해집니다.

색상은 팀 단위로 스코어보드, 제단 블록, 색깔 블록 lore, 머리 위 `ItemDisplay`, 제단 위 `TextDisplay`에 동일하게 적용합니다.

## 머리 위 식별 표시

각 플레이어를 식별할 수 있도록 플레이어 머리 위에 `ItemDisplay` 색깔 블록이 따라다닙니다.

구현 기준:

- `PLAYING` 진입 시 팀 색상 기준으로 플레이어별 `ItemDisplay` 생성
- 표시 아이템은 팀 색상 블록
- 플레이어 머리 위 위치로 주기적 teleport
- 게임 종료, 퇴장, 사망 처리 시 제거 또는 재연결

## 색깔 블록

색깔 블록은 제단 점령과 상태 표시를 담당하는 핵심 아이템입니다.

- 핫바 4번 슬롯에 고정됩니다.
- 플레이어가 이동, 드래그, 버리기, 교체할 수 없습니다.
- 신호기 바로 위에만 설치할 수 있습니다.
- 제단 상태와 실시간으로 연동됩니다.
- lore에 점령 제단 수, 누적 활성화율, 초당 증가량을 표시합니다.

## 구현 메모

Paper 1.21.11에서는 Adventure `Component`와 `TextColor.fromHexString()`으로 HEX 색상을 표시합니다.

```java
Component line = Component.text(player.getName() + " >> ")
    .append(Component.text(colorName, TextColor.fromHexString(hexColor)));
```

입장 직후 시작 전 스코어보드는 미지정 플레이어를 다음처럼 표시합니다.

```text
PlayerA >> 준비
```

관리자가 `/game 팀지정 PlayerA 빨강`을 실행하면 시작 전 스코어보드에는 다음처럼 표시할 수 있습니다.

```text
PlayerA >> 빨강 팀
```
