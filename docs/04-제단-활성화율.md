# 제단과 활성화율

## 문서 역할

제단 점령, 제단 대체, 누적 활성화율, 승리 조건을 정의합니다.

## 제단 점령 규칙

- 플레이어가 팀 색염료로 제단 신호기를 클릭하면 서버가 신호기 위에 팀 색유리를 설치하고 해당 팀이 제단을 점령합니다.
- 색유리 아래 Y 좌표에는 반드시 신호기가 있어야 합니다.
- 빈 제단은 누구나 점령할 수 있습니다.
- 이미 점령된 제단은 다른 플레이어가 자신의 색깔 블록으로 대체할 수 있습니다.
- 제단이 대체되면 기존 점령자의 활성화율 상승 속도가 감소합니다.
- 새 점령자의 활성화율 상승 속도는 증가합니다.
- 기존에 누적된 활성화율은 즉시 차감되지 않습니다.

## 제단 파괴 규칙

- 제단 위에 설치된 색유리는 맨손 또는 어떤 아이템으로도 부술 수 있습니다.
- 자신의 제단과 다른 플레이어의 제단 모두 부술 수 있습니다.
- 다른 플레이어가 나의 제단을 부수면 즉시 해당 제단의 점령 상태가 해제됩니다.
- 제단이 해제되면 점령 제단 수가 줄어들고, 활성화율 상승 속도가 즉시 하락합니다.
- 제단 위 `TextDisplay`와 발광 효과는 즉시 제거되거나 비활성 상태로 갱신됩니다.
- 이미 누적된 활성화율 자체는 즉시 차감하지 않고, 이후 증가 속도만 하락합니다.

## 누적 활성화율 규칙

활성화율은 고정 점유율이 아니라 시간에 따라 누적되는 값입니다.

```text
틱당 활성화율 증가량 = 기본 증가량 * 점령한 제단 수
```

예시:

| 점령 제단 수 | 초당 증가량 | 100%까지 걸리는 시간 |
| ---: | ---: | ---: |
| 0개 | 0% | 진행 불가 |
| 1개 | 0.04% | 2500초 |
| 2개 | 0.08% | 1250초 |
| 3개 | 0.12% | 약 834초 |
| 4개 | 0.16% | 625초 |
| 5개 | 0.20% | 500초 |

현재 기본 설정은 `activation-tick-seconds: 1`, `base-increase-per-altar: 0.04`입니다.  
5개 제단을 모두 점령해도 초당 0.20%만 증가하므로 교전 시간이 길어집니다.

## 승리 조건

제단 누적 활성화율이 100%에 도달한 플레이어가 승리합니다.  
모든 제단을 점령할 필요는 없습니다.

## 제단 상태 표시

점령된 제단은 월드 안에서 다음 정보를 표시합니다.

- 색깔 블록
- 점령 플레이어 이름
- 제단 누적 활성화율
- 발광 효과

자세한 표시 방식은 [[05-UI-피드백]]에서 정의합니다.

## 현상수배 규칙

- 한 팀이 제단을 3개 이상 점령하면 해당 팀은 현상수배 상태가 됩니다.
- 현상수배 팀의 모든 온라인 팀원은 팀 색상 발광 효과를 얻습니다.
- 점령 제단이 3개 미만으로 내려가면 현상수배가 해제되고 발광 효과도 제거됩니다.
- 재접속 또는 리스폰 시에도 팀이 현상수배 상태이면 발광 효과를 다시 적용합니다.
- 현상수배 진입과 해제는 참가자 전체에게 안내합니다.
