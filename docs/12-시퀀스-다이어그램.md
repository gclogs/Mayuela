# 시퀀스 다이어그램

## 문서 역할

Mayuela의 주요 유스케이스가 어떤 순서로 실행되는지 정의합니다.  
Paper 이벤트, 서비스 호출, UI 갱신, 상태 저장의 흐름을 맞추기 위한 개발 기준입니다.

## 1. 플레이어 입장

```mermaid
sequenceDiagram
    participant Player
    participant JoinCommand as /입장 Command
    participant GamePlayerService
    participant ScoreboardService

    Player->>JoinCommand: /입장
    JoinCommand->>GamePlayerService: join(player)
    GamePlayerService->>GamePlayerService: 정원 및 세션 검증
    GamePlayerService->>ScoreboardService: updateWaitingBoard()
    ScoreboardService-->>Player: 준비 상태 스코어보드 표시
```

## 1.1. 팀 수동 지정

```mermaid
sequenceDiagram

    GameCommand->>ScoreboardService: updateWaitingBoard()
    ScoreboardService-->>Admin: PlayerA >> 빨강 팀
```

## 2. 게임 시작

```mermaid
sequenceDiagram
    participant Admin
    participant GameCommand as /game 시작
    participant GameSessionService
    participant MapService
    participant InventoryService
    participant ScoreboardService
    participant SchedulerService

    Admin->>GameCommand: /game 시작
    GameCommand->>GameSessionService: startGame()
    GameSessionService->>MapService: validatePlayableMap()
    MapService-->>GameSessionService: valid
    GameSessionService->>GameSessionService: phase = READY
    GameSessionService->>InventoryService: giveStartItems()
    InventoryService->>InventoryService: 색깔 블록 9번 슬롯 고정
    GameSessionService->>ScoreboardService: showReadyBoard()
    GameSessionService->>SchedulerService: startReadyCountdown()
```

sequenceDiagram
