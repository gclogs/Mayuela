# 변경로그

이 문서는 Mayuela의 주요 변경 사항을 기록합니다.  
형식은 사람이 읽기 쉬운 릴리즈 노트와 개발 변경 로그를 겸합니다.

## Unreleased

- 필드 코인을 `model.yml`의 `system-items.field_coin` ItemsAdder id/fallback material로 생성하도록 변경
- 필드 코인 드랍 시 발광 효과와 `n초 뒤 제거됩니다.` TextDisplay 안내를 추가하고 획득/만료 시 같이 제거되도록 변경
- 현상수배 기준을 제단 3개 이상이 아니라 1등 팀의 리드 격차 기반으로 재설계하는 기획 문서 추가
- 현상수배 플레이어 처치 시 설정값 기준 코인 8개를 1회만 지급하고, 재처치/팀킬/인벤토리 공간 부족 상황에 대한 안내 메시지 추가
- 스코어보드에 현상수배 팀 표시 추가
- 현상수배 플레이어 머리 위 팀 색상 `ItemDisplay` 아래에 `TextDisplay` 현상수배 문구 표시 추가

- 리스폰 후 3초 이동 잠금, 이후 5초 스폰 무적 적용
- 스폰 무적 대상을 밀치기 막대기로 2초 안에 3회 타격하면 공격자에게 3초 속박 적용

- 밀치기 막대기 플레이어당 보유 한도 추가, 기본 3개 및 `/game 막대기최대 <개수>` 운영 명령어 추가
- 밀치기 막대기는 상대가 스폰 무적/밀치기 저항 상태여도 플레이어 타격 시 즉시 1개 소모되도록 수정
- 밀치기 막대기가 플레이어가 아닌 엔티티를 타격해도 1개 소모되도록 수정
- `READY`/`PLAYING` 중인 참가자는 모든 아이템을 버릴 수 없도록 변경
- 팀이 제단 3개 이상을 점령하면 현상수배 상태가 되고 팀 색상 플레이어 발광 효과를 받도록 추가
- 기본 지급 곡괭이를 제거하고, 맨손 또는 모든 아이템으로 제단 색유리를 파괴할 수 있도록 변경
- 왼손 F 슬롯 상점 잠금 아이템도 `model.yml`의 ItemsAdder id/fallback material로 생성되도록 변경
- `/game 팀전 시작`, `/game 개인전 시작` 명령어 추가 및 팀전/개인전 편성 테스트 태스크 추가
- 코인 드롭 룰을 1~10명 전체로 확장하고 5명 게임이 `coin.rules.5`를 사용하도록 수정
- `Gaensta`를 기본 통계 제외 대상에 추가하고 제외 플레이어 이벤트를 매치 통계에서 누락 처리
- 제단 설치기와 상점 아이템을 `model.yml` ItemsAdder id 기반 생성 방식으로 변경

- 게임 진행 중 F키로 은행 GUI를 열 수 있도록 변경하고 보조 손 교체는 계속 차단
- 은행 구매 비용은 필드에서 주운 `Mayuela 코인` 아이템으로만 차감하도록 명세 정리

### 구조

- `command`, `listener`, `model`, `repository`, `service` 패키지 분리
- Listener/Command에서 Service로 위임하는 구조 적용
- YAML 접근을 `ConfigRepository`로 집중
- Display 엔티티 관리를 `DisplayService`로 집중

### 알려진 제한

- 상점 GUI와 장비 업그레이드 상세는 아직 미구현
- ItemsAdder 연동은 `model.yml`의 id를 기준으로 CustomStack을 reflection 호출하고 fallback material을 지원
- 맵 영역 내부/외부 판정은 아직 최소 구현
- 발광 효과의 팀 색상 처리는 아직 정교화 필요
- 제단 블록 보호와 맵 초기화는 추가 구현 필요
