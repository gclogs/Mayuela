# 현상수배 보상 및 디스플레이

## 목적

현상수배 시스템은 제단을 많이 점령한 팀에게 리스크를 부여하고, 추격하는 팀에게 명확한 보상을 제공하기 위한 역전 장치입니다.

## 발동 조건

- 한 팀이 제단 3개 이상을 점령하면 해당 팀은 현상수배 상태가 됩니다.
- 현상수배 팀의 모든 온라인 플레이어는 팀 색상 발광 효과를 얻습니다.
- 현상수배 팀의 플레이어 머리 위에는 기존 팀 색상 `ItemDisplay`가 유지됩니다.
- 팀 색상 `ItemDisplay` 아래에는 `TextDisplay`로 `현상수배` 문구가 따라다닙니다.

## 처치 보상

- 현상수배 상태의 플레이어를 다른 팀 플레이어가 처치하면 처치자는 코인 8개를 획득합니다.
- 같은 팀 처치는 현상수배 보상을 지급하지 않습니다.
- 같은 현상수배 플레이어에 대한 보상은 현상수배 상태 1회당 1번만 지급합니다.
- 이미 보상이 지급된 현상수배 플레이어를 다시 처치하면 추가 코인은 지급하지 않고 안내 메시지를 출력합니다.
- 처치자의 인벤토리에 공간이 없으면 코인을 지급하지 않고 안내 메시지를 출력합니다.

## 초기화 조건

- 현상수배 상태가 해제되면 해당 팀의 현상수배 보상 지급 이력을 초기화합니다.
- 게임이 종료되거나 런타임 상태가 초기화되면 모든 팀의 현상수배 보상 지급 이력을 초기화합니다.

## UI 표시

- 스코어보드에는 현재 현상수배 팀을 `현상수배 [팀 색상]` 형식으로 표시합니다.
- 여러 팀이 동시에 현상수배 상태이면 한 줄에 쉼표로 구분해서 표시합니다.
- 리스폰 또는 재접속 시에도 현상수배 발광과 머리 위 `TextDisplay`를 복구합니다.
