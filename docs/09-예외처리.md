# 예외 처리

## 문서 역할

게임 중 발생할 수 있는 사망, 리스폰, 퇴장, 강제 종료, 아이템 이동 방지 규칙을 정의합니다.

## 사망 처리

게임 도중 플레이어가 사망해도 보유 아이템을 모두 잃지 않습니다.

처리 방식:

- 사망 드롭 차단
- 사망 직전 인벤토리 저장
- 리스폰 후 인벤토리 복구
- 리스폰 위치는 등록된 게임 스폰으로 지정
- 리스폰 후 이동속도 II와 조건부 힘 버프 복구
- 리스폰 후 3초 동안 이동 잠금
- 이동 잠금 종료 후 5초 동안 스폰 무적 적용
- 스폰 무적 중인 플레이어를 밀치기 막대기로 2초 안에 3회 타격하면 공격자에게 3초 속박 적용
- 색깔 블록은 핫바 4번 슬롯에 복구
- 게임 참가자는 낙하 피해를 받지 않음

## 색깔 블록 이동 차단

색깔 블록은 플레이어가 조작할 수 없는 고정 아이템입니다.

## READY 세션 행동 제한

`/game 시작` 이후 `READY` 카운트다운 중에는 참가자가 아이템을 버리거나 블록을 설치할 수 없습니다.

목적:

- 시작 전 아이템 손실 방지
- 색유리 또는 일반 블록을 미리 설치하는 행위 방지
- 모든 팀이 동일한 조건으로 `PLAYING`에 진입하도록 보장

차단 대상:

- 인벤토리 클릭
- 인벤토리 드래그
- 숫자키 교체
- Q 키 버리기
- 보조 손 교체
- 리스폰 과정에서 슬롯이 바뀌는 상황

구현 기준:

```java
event.setCancelled(true);
```

대상 이벤트:

- `InventoryClickEvent`
- `InventoryDragEvent`
- `PlayerDropItemEvent`
- `PlayerSwapHandItemsEvent`
- `PlayerDeathEvent`
- `PlayerRespawnEvent`

## 갑옷 이동 차단

게임 중 지급된 갑옷은 플레이어가 임의로 벗거나 갈아입을 수 없습니다.
또한 게임 중 갑옷 내구도 감소를 차단해 갑옷이 깨지지 않게 합니다.

차단 대상:

- 갑옷 슬롯 클릭
- 갑옷을 shift-click으로 장착하거나 해제
- 커서 아이템으로 갑옷 교체
- 숫자키를 통한 갑옷 교체

## 맵 밖 이동

게임 중 참가자는 등록된 맵 영역 밖으로 이동할 수 있습니다.  
`PlayerMoveEvent` 기반 경계 차단은 사용하지 않습니다.

## 블록 파괴 차단

`READY`와 `PLAYING` 세션 중 게임 참가자는 기본적으로 어떤 블록도 부술 수 없습니다.

예외:

- `PLAYING` 세션
- 등록된 제단의 팀 색유리

위 조건을 만족하면 맨손 또는 어떤 아이템으로도 제단 색유리 파괴를 허용합니다.

## 재접속 복구

게임 참가자가 게임 중 나갔다가 다시 들어오면 참가 상태를 유지합니다.

복구 대상:

- 핫바 4번 슬롯의 제단 색유리
- 이동속도 II
- 조건부 힘 버프
- 머리 위 `ItemDisplay`

## 게임 종료 시 아이템 초기화

게임이 종료되면 게임 중 지급되거나 획득한 아이템을 초기화합니다.

처리 방식:

- 인벤토리 전체 초기화
- 갑옷 슬롯 초기화
- 보조 손 슬롯 초기화
- 색깔 블록, 기본 장비, 코인, 상점 장비 제거
- 게임 종료 후 시작 전 갑옷이 다시 입혀지는 상황을 방지

## 퇴장 처리

플레이어가 게임 도중 나가면 다음 처리를 진행합니다.

- 점령 상태 유지 여부 결정 필요
- 머리 위 `ItemDisplay` 제거
- 제단 위 표시 갱신
- 스코어보드 갱신

## 강제 종료 처리

관리자가 `/game 종료`를 실행하면 다음을 정리합니다.

- 모든 제단 점령 상태 초기화
- 제단 위 `TextDisplay` 제거
- 발광 효과 제거
- 신호기 위에 설치된 팀 제단 색유리 제거
- 코인 드롭 아이템 제거
- 플레이어 인벤토리 복구
- 스코어보드 제거 또는 초기화
