# 아이템, 상점, 코인

## 문서 역할

기본 지급 아이템, 상점 NPC, 코인 드롭, 장비 구매, ItemsAdder 연동을 정의합니다.

| 아이템 | 설명 |
| --- | --- |
| 가죽 헬멧 | 플레이어 색상으로 염색 지급 |
| 가죽 흉갑 | 플레이어 색상으로 염색 지급 |
| 가죽 바지 | 플레이어 색상으로 염색 지급 |

| 제단 설치기 | 핫바 4번 슬롯에 고정 지급, `model.yml`의 ItemsAdder id로 리소스 연동, 신호기 클릭 시 제단 색유리 설치 |
| 보조 손 잠금 아이템 | 보조 손 슬롯에 고정 지급, 리소스팩으로 숨김 |
| 이동속도 II | 게임 종료 시까지 유지 |

## 장비 잠금 규칙

- 게임 중 지급된 갑옷은 인벤토리에서 따로 벗거나 갈아입을 수 없습니다.
- 게임 중 지급된 갑옷은 내구도가 감소하지 않습니다.
- 갑옷 슬롯 클릭, 갑옷 교체, 갑옷 shift-click 이동은 차단합니다.
- 제단 설치기는 핫바 4번 슬롯에 고정되며 이동할 수 없습니다.
- 보조 손에는 전용 잠금 아이템을 넣고, 리소스팩으로 보이지 않게 처리합니다.
- 게임 진행 중 참가자는 F키로 은행 GUI를 열 수 있으며, 보조 손 교체 동작은 취소됩니다.
- 은행 구매 비용은 필드에서 주운 `Mayuela 코인` 아이템으로만 차감합니다.
- `READY` 또는 `PLAYING` 중인 참가자는 아이템을 버릴 수 없습니다.
- 보조 손 잠금 아이템은 이동, 드래그, 버리기가 불가능합니다.
- 게임 종료 시 게임 중 보유한 모든 아이템과 갑옷은 초기화됩니다.

## 제단 설치기와 파괴 규칙

- 플레이어는 색유리 블록을 직접 설치하지 않습니다.
- 핫바 4번의 제단 설치기로 신호기를 클릭하면 서버가 신호기 위에 팀 색유리를 설치합니다.
- 설치 성공 또는 실패 사유는 플레이어에게 안내 메시지로 표시합니다.
- 제단 위 색유리는 맨손 또는 어떤 아이템으로도 부술 수 있습니다.
- 색유리 아래에는 반드시 신호기가 있어야 설치할 수 있습니다.
- 제단 색유리를 부숴도 블록 아이템은 드롭되지 않습니다.

## 코인 랜덤 드롭

코인은 맵 안 랜덤 위치에 드롭됩니다.  
TPS를 고려해 플레이어 주변 청크에서 제한된 횟수만 후보 위치를 탐색합니다.

드롭 조건:

- 공중이 아닌 땅 위에 드롭
- 물 위 제외
- 나뭇잎 위 제외
- 너무 높은 Y 좌표 제외
- 설정된 시간 동안 획득되지 않으면 자동 제거
- 게임 시작 후 첫 코인은 약 1초 뒤부터 생성 시도
- 후보 위치 탐색은 드롭 주기마다 최대 32회 시도
- 획득 시 내부 점수만 증가하지 않고 `Mayuela 코인` 아이템이 플레이어 인벤토리에 들어감
- 인벤토리에 공간이 없으면 코인은 필드에 남고 획득되지 않음

```yaml
coin:
  despawn-seconds: 30
  max-dropped-items: 40
  rules:
    4:
      interval-seconds: 8
      amount: 4
    6:
      interval-seconds: 7
      amount: 5
    8:
      interval-seconds: 6
      amount: 6
    10:
      interval-seconds: 5
      amount: 7
```

이미 생성된 `game.yml`은 기본값이 자동으로 덮어써지지 않습니다.  
기존 서버는 `/game 코인설정 <4|6|8|10> <주기초> <금액>`으로 운영자가 직접 갱신합니다.

## 제단 미점령 팀 보정 버프

- 팀이 점령한 제단이 0개이면 팀원 모두 힘 버프 대상이 됩니다.
- 게임이 `PLAYING`으로 전환된 뒤 설정된 지연 시간, 기본 30초가 지나도 제단을 설치하지 못하면 힘 버프를 지급합니다.
- 팀이 제단을 하나라도 점령하면 힘 버프는 즉시 제거됩니다.
- 팀이 다시 모든 제단을 잃으면 지연 시간이 다시 시작됩니다.
- 힘 버프는 중복 재지급하지 않고, 팀 상태가 변경될 때만 적용/제거합니다.

## ItemsAdder 연동

`model.yml`의 `itemsadder-id`를 통해 ItemsAdder와 연동합니다.  
서버에 ItemsAdder가 있으면 해당 id의 `CustomStack`을 가져오고, 없거나 id가 잘못되면 fallback material로 대체합니다.

```yaml
flags:
  RED:
    itemsadder-id: mayuela:flag_red
    fallback-material: RED_DYE

shop-items:
  knockback_stick:
    itemsadder-id: mayuela:knockback_stick
    fallback-material: STICK
  jump_boost:
    itemsadder-id: mayuela:jump_boost
    fallback-material: RABBIT_FOOT
  knockback_resistance:
    itemsadder-id: mayuela:knockback_resistance
    fallback-material: SHIELD
  arrow:
    itemsadder-id: mayuela:arrow
    fallback-material: ARROW

system-items:
  offhand_lock:
    itemsadder-id: mayuela:offhand_lock
    fallback-material: PAPER
  field_coin:
    itemsadder-id: mayuela:field_coin
    fallback-material: GOLD_NUGGET
```
