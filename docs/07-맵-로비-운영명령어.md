# 맵, 로비, 운영 명령어

## 문서 역할

맵 등록, 로비 등록, 게임 스폰 등록, 제단 등록, 상점 NPC 등록, 운영 명령어를 정의합니다.

## 맵 등록 조건

맵은 `position1`과 `position2`를 지정해 저장합니다.  
맵이 등록되어 있어야 게임을 시작할 수 있습니다.

필수 요소:

- 맵 영역 `position1`
- 맵 영역 `position2`
- 제단 1개 이상
- 상점 NPC 위치
- 게임 스폰 위치
- 선택 사항으로 로비 위치

## 로비

`/입장 로비등록`을 사용하면 현재 위치를 로비로 저장합니다.  
`game.yml`의 `lobby.enabled`가 `true`이면 게임 시작 시 참가자를 로비로 텔레포트합니다.

## 게임 스폰

`/game 스폰등록`을 사용하면 현재 위치를 실제 게임 시작 스폰으로 저장합니다.  
게임 스폰은 `READY` 카운트다운 종료 후 `PLAYING`으로 전환될 때 모든 참가자가 이동하는 위치입니다.

게임 스폰이 등록되지 않으면 `/game 시작`은 실패해야 합니다.

## 명령어

| 명령어 | 설명 | 권한 |
| --- | --- | --- |
| `/입장` | 게임 입장 | 모든 플레이어 |
| `/입장 로비등록` | 현재 위치를 로비로 등록 | 관리자 |
| `/game 스폰등록` | 현재 위치를 게임 스폰으로 등록 | 관리자 |
| `/game 팀지정 <플레이어> <색상>` | 플레이어를 특정 색상 팀으로 수동 지정 | 관리자 |
| `/game 팀해제 <플레이어>` | 플레이어의 수동 팀 지정을 해제 | 관리자 |
| `/game 시작` | 팀전 게임 시작, 기존 호환 명령 | 관리자 |
| `/game 팀전 시작` | 2명 단위 팀전 시작 | 관리자 |
| `/game 개인전 시작` | 1명 단위 개인전 시작 | 관리자 |
| `/game 종료` | 게임 강제 종료 | 관리자 |
| `/game reload` | `game.yml`, `alter.yml`, `maps.yml`, `model.yml` 다시 로드 | 관리자 |
| `/game 맵 pos1` | 맵 첫 번째 지점 지정 | 관리자 |
| `/game 맵 pos2` | 맵 두 번째 지점 지정 | 관리자 |
| `/game 맵 저장 <이름>` | 맵 저장 | 관리자 |
| `/game 제단등록 <이름>` | 현재 위치를 제단으로 등록 | 관리자 |
| `/game 제단목록` | 등록된 제단 이름, 월드, 좌표 확인 | 관리자 |
| `/game 상점등록` | 현재 위치를 상점 NPC 위치로 등록 | 관리자 |

## 제단 목록

`/game 제단목록`은 `alter.yml`에 저장된 제단 정보를 읽어 표시합니다.

```text
altar_1 - world (20, 65, 20)
altar_2 - world (80, 65, 40)
```
