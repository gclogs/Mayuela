# ADR-001 Paper 1.21.11 기준 사용

## 상태

승인됨

## 배경

Mayuela는 Paper 서버 기반 미니게임 플러그인입니다.  
기획 문서에서는 `ItemDisplay`, `TextDisplay`, Adventure HEX 색상, Paper scheduler를 사용하도록 정의했습니다.

현재 Gradle 의존성도 `paper-api:1.21.11-R0.1-SNAPSHOT`을 기준으로 사용합니다.

## 선택지

- A안: Minecraft/Paper `1.21` 기준으로 개발
- B안: Minecraft/Paper `1.21.11` 기준으로 개발

## 결정

Paper `1.21.11` 기준으로 개발합니다.

## 이유

- 문서에서 검토한 API 기준이 `1.21.11`입니다.
- compile API와 테스트 서버 버전을 맞추면 API 차이로 인한 혼란을 줄일 수 있습니다.
- `ItemDisplay`, `TextDisplay`, Adventure Component 기반 표시 구현을 명확하게 고정할 수 있습니다.

## 결과

- `build.gradle`의 `compileOnly`와 `runServer.minecraftVersion`을 `1.21.11` 기준으로 맞춥니다.
- 이후 Paper 버전을 올릴 때는 별도 ADR을 작성합니다.
