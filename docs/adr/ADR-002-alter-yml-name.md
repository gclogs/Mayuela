# ADR-002 alter.yml 파일명 유지

## 상태

승인됨

## 배경

기획 요구사항에서는 제단 정보를 `alter.yml`에 저장한다고 명시했습니다.  
영어 단어 기준으로는 `altar.yml`이 자연스럽지만, 현재 문서와 코드에서는 요구사항을 우선하여 `alter.yml`을 사용하고 있습니다.

## 선택지

- A안: 요구사항 그대로 `alter.yml` 사용
- B안: 오타 가능성을 교정해 `altar.yml` 사용
- C안: 둘 다 지원하고 신규 저장은 `altar.yml` 사용

## 결정

현재 MVP 단계에서는 `alter.yml`을 유지합니다.

## 이유

- 기획 문서와 사용자 요구사항을 그대로 추적할 수 있습니다.
- 초기 개발 단계에서 파일명이 바뀌면 문서와 구현이 어긋날 수 있습니다.
- 1인 개발 기준에서는 우선 요구사항과 코드의 일치를 우선합니다.

## 결과

- `ConfigRepository`는 제단 정보를 `alter.yml`에 저장합니다.
- 추후 파일명을 `altar.yml`로 교정하려면 마이그레이션 ADR을 작성합니다.
