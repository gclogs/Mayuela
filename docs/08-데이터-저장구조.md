# 데이터 저장 구조

## 문서 역할

Mayuela가 사용하는 YAML 파일의 책임과 필드 구조를 정의합니다.

## 파일 역할

| 파일 | 역할 |
| --- | --- |
| `game.yml` | 게임 공통 설정, 로비, 코인, 활성화율 설정 |
| `maps.yml` | 맵 영역, 상점 위치, 맵 단위 정보 |
| `alter.yml` | 등록된 제단 이름, 월드, 좌표 |
| `players.yml` | 플레이어 색상, 코인, 활성화율, 점령 제단 |
| `model.yml` | 팀별 제단 설치기와 상점 아이템의 ItemsAdder id, fallback 아이템 |

## alter.yml

```yaml
altars:
  altar_1:
    world: world
    x: 20
    y: 65
    z: 20
```

주의: `alter.yml`은 현재 요구사항의 표기를 따릅니다. 구현 전 `altar.yml`로 교정할지 결정이 필요합니다.

## model.yml

```yaml
flags:
  RED:
    itemsadder-id: mayuela:flag_red
    fallback-material: RED_DYE
  LIGHT_BLUE:
    itemsadder-id: mayuela:flag_light_blue
    fallback-material: LIGHT_BLUE_DYE

shop-items:
  knockback_stick:
    itemsadder-id: mayuela:knockback_stick
    fallback-material: STICK
  jump_boost:
    itemsadder-id: mayuela:jump_boost
    fallback-material: RABBIT_FOOT
  knockback_resistance:
    itemsadder-id: mayuela:knockback_resistance
    fallback-material: SHIELD
  arrow:
    itemsadder-id: mayuela:arrow
    fallback-material: ARROW

system-items:
  offhand_lock:
    itemsadder-id: mayuela:offhand_lock
    fallback-material: PAPER
  field_coin:
    itemsadder-id: mayuela:field_coin
    fallback-material: GOLD_NUGGET
```

`itemsadder-id`는 ItemsAdder에 등록된 커스텀 아이템 id를 그대로 사용합니다.  
ItemsAdder가 없거나 id가 잘못된 경우 `fallback-material`로 Paper 기본 아이템을 생성하되, Mayuela PDC 태그는 그대로 유지합니다.
