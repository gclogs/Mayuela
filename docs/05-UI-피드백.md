# UI와 피드백

## 문서 역할

플레이어가 게임 상태를 이해하는 모든 표시 요소를 정의합니다.  
스코어보드, 색깔 블록 lore, 제단 위 `TextDisplay`, 발광 효과가 이 문서의 범위입니다.

## 게임 시작 전 스코어보드

게임 시작 전에는 플레이어별 준비 상태 또는 운영자가 수동 지정한 팀 색상을 표시합니다.

```text
[플레이어 이름] >> 준비
```

예시:

```text
Steve >> 준비
Alex >> 빨강 팀
Mayu >> 준비
```

수동 지정된 팀 색상 이름에는 해당 HEX 색상을 적용합니다.

## 게임 진행 중 스코어보드

게임 중에는 진행률 기준 상위 5명을 표시합니다.

```text
1위 빨강 (60.0%)
2위 노랑 (45.0%)
3위 파랑 (30.0%)
4위 초록 (20.0%)
5위 분홍 (10.0%)
```

스코어보드 제목은 현재 게임 진행 시간을 포함합니다.

```text
playtime 03:25
```

갱신 조건:

- 활성화율 누적 틱 실행
- 제단 점령자 변경
- 플레이어 사망 후 리스폰
- 플레이어 퇴장

추가 표시:

- 본인 팀 색상
- 본인 팀원 목록

## 플레이어 머리 위 ItemDisplay

게임 진행 중 각 플레이어 머리 위에는 팀 색유리 `ItemDisplay`를 표시합니다.

표시 기준:

- 플레이어 위치 기준 Y축 `+2.85`
- 1틱 단위 추적
- 게임 종료, 서버 퇴장, 표시 초기화 시 제거

## 게임 종료 결과 통계

승리 팀이 결정되면 채팅으로 게임 결과를 안내합니다.

```text
===== Mayuela 게임 결과 =====
승리 팀: 빨강
게임 플레이 타임: 03:25
빨강 팀 코인: 32
노랑 팀 코인: 18
파랑 팀 코인: 9
============================
```

팀별 코인은 해당 팀원들이 게임 중 획득한 코인의 합계입니다.

## 색깔 블록 lore

색깔 블록 아이템은 핫바 9번 슬롯에 고정되며 제단 상태와 실시간으로 연동됩니다.

```text
Mayuela 제단 블록
이 블록을 제단 위에 올리면 제단을 활성화할 수 있습니다.

현재 활성화율: 60%
점령한 제단: 3 / 5
초당 증가량: 3%
```

## 제단 위 TextDisplay

게임 시작 시 등록된 모든 제단 위치에는 `TextDisplay`를 띄워 어디에 색깔 블록을 설치해야 하는지 표시합니다.

빈 제단 표시:

```text
제단 설치 위치
altar_1
```

점령된 제단 위에 설치된 색깔 블록 위에는 점령 상태 `TextDisplay`를 띄웁니다.

```text
Steve
누적 활성화율 60%
```

규칙:

- 점령 플레이어 이름을 표시합니다.
- 제단 누적 활성화율을 표시합니다.
- 텍스트 색상은 점령 플레이어의 HEX 색상을 사용합니다.
- 점령자 변경 시 기존 표시를 제거하고 새 표시로 갱신합니다.
- 제단이 파괴되어 비어 있으면 다시 설치 위치 안내 표시로 돌아갑니다.
- 게임 종료 또는 맵 초기화 시 제거합니다.

## 발광 효과

제단이 활성화 중임을 직관적으로 보여주기 위해 점령된 제단에 발광 효과를 적용합니다.

- 점령된 제단은 점령 플레이어 색상으로 발광합니다.
- 비어 있는 제단은 발광하지 않습니다.
- 점령자가 변경되면 발광 색상도 변경됩니다.

## 현상수배 플레이어 발광

제단을 3개 이상 점령한 팀은 현상수배 상태가 되며, 해당 팀원은 팀 색상 발광 효과를 얻습니다.

- 발광 색상은 팀 색상과 동일하게 표시합니다.
- 현상수배 상태는 제단 점령/파괴 직후 갱신합니다.
- 재접속 또는 리스폰 후에도 현상수배 팀원은 발광 상태를 복구합니다.
- 현상수배가 해제되면 플레이어 발광 효과를 제거합니다.

## 제단 설치/제거 안내

제단이 설치되거나 제거되면 게임 참가 중인 모든 플레이어에게 안내 메시지를 보냅니다.

설치 안내:

```text
빨강 색깔이 제단 altar_1을 설치했습니다.
```

제거 안내:

```text
빨강 색깔의 제단 altar_1이 제거되었습니다.
```

색상 이름은 해당 플레이어의 HEX 색상으로 표시합니다.

## 보스바

보스바에는 현재 1위의 색상, 진행률, 점령 누적 시간을 표시합니다.

```text
1위 빨강 (60.0%) | 점령 누적 시간 02:15 |
```

보스바 진행률은 1위 플레이어의 누적 진행률을 기준으로 합니다.
