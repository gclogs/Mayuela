# 코인 드랍 공평성 모니터링

## 현재 드랍 방식

- 코인은 청크 단위로 균등 분배되지 않습니다.
- 현재 방식은 게임 맵 안에 있는 온라인 참가자 중 1명을 균등 랜덤으로 앵커 플레이어로 선택합니다.
- 선택된 앵커 플레이어의 현재 위치를 기준으로 `coin.search-radius-blocks` 반경 안에서 랜덤 X/Z 좌표를 뽑습니다.
- 해당 X/Z의 최고 지상 Y 좌표를 찾고, 맵 내부이며 공기/물/나뭇잎이 아닌 지형이면 코인을 드랍합니다.
- 적합한 위치를 32회 안에 찾지 못하면 해당 드랍 주기는 실패로 처리합니다.
- 드랍된 필드 코인은 발광 효과를 가지며, 위에 `n초 뒤 제거됩니다.` TextDisplay를 표시합니다.
- TextDisplay는 1초마다 남은 시간을 갱신하고, 코인이 획득되거나 만료되면 같이 제거됩니다.

## 필드 코인 모델

필드 코인은 `model.yml`의 `system-items.field_coin` 설정을 사용합니다.

```yaml
system-items:
  field_coin:
    itemsadder-id: mayuela:field_coin
    fallback-material: GOLD_NUGGET
```

ItemsAdder가 없거나 id가 잘못되면 `fallback-material`로 코인을 생성합니다.
코인 아이템에는 기존 `mayuela:coin` PDC 태그가 유지되며, 운영자 확인용으로 `mayuela:coin_itemsadder_id` 태그도 기록합니다.

## 공평성 판단 기준

- 앵커 선택 횟수: 코인 생성 기회가 플레이어별로 균등하게 주어졌는지 확인합니다.
- 실제 획득 횟수/코인량: 플레이어가 실제로 코인을 얼마나 회수했는지 확인합니다.
- 앵커 대비 획득 격차: 특정 플레이어 주변에는 많이 생성되지만 다른 플레이어가 계속 먹는지 확인합니다.
- 청크 좌표: 특정 지역이나 특정 청크에 코인이 몰리는지 확인합니다.
- 위치 탐색 실패 수: 맵 구조 때문에 코인이 너무 자주 생성 실패하는지 확인합니다.

## 운영자 모니터링

`/game 모니터링`은 다음 정보를 출력합니다.

- 현재 코인 드랍 방식
- 청크 단위 드랍 여부
- 현재 필드 코인 수와 최대 필드 코인 수
- 현재 참가 인원에 적용 중인 코인 룰
- 성공 드랍 수와 위치 탐색 실패 수
- 플레이어별 앵커 선택 횟수, 앵커 비율, 실제 획득 횟수, 실제 획득 코인량

## 매치 통계 YAML

`COIN_DROPPED` 이벤트에는 다음 데이터가 저장됩니다.

- 코인 엔티티 UUID
- 드랍 코인량
- 드랍 위치
- 드랍 청크 좌표
- 앵커 플레이어
- 앵커 팀
- 앵커 후보자 수
- 앵커 플레이어와 드랍 위치의 거리

`COIN_PICKED_UP` 이벤트에는 다음 데이터가 저장됩니다.

- 획득 플레이어
- 획득 팀
- 코인 엔티티 UUID
- 획득 코인량
- 획득 위치
- 획득 청크 좌표

## 해석 방법

- 앵커 비율은 비슷한데 획득량 차이가 크면 플레이어 이동 경로, 상점/제단 위치, 중앙 교전 밀도 영향일 가능성이 큽니다.
- 특정 플레이어의 앵커 비율 자체가 높으면 짧은 테스트 판의 표본 부족일 수 있으므로 여러 판을 합산해서 봐야 합니다.
- 위치 탐색 실패가 많으면 맵 등록 범위, 수면/나뭇잎 지형, 높은 구조물, `coin.search-radius-blocks` 값을 조정해야 합니다.
- 특정 청크에 드랍이 몰리면 앵커 플레이어들이 주로 머무는 동선이나 맵 구조가 코인 경제를 한쪽으로 기울게 만들 수 있습니다.
