# Mayuela 세션 인수인계서

작성일: 2026-06-12  
대상: Mayuela Paper 1.21.11 기반 미니게임 플러그인 유지보수/확장 개발자

## 목적

이 폴더는 지금까지의 대화에서 확정된 요구사항, 실제 구현 상태, 위험 요소, 테스트 기준을 한곳에 모은 세션 인수인계 문서입니다.

기존 `docs/`에는 초기 기획부터 여러 번의 변경사항이 누적되어 있습니다. 일부 문서는 현재 구현과 어긋난 내용이나 오래된 기준을 포함할 수 있습니다. 새 개발자는 이 세션 폴더를 먼저 읽고, 세부 설계가 필요할 때 기존 문서로 내려가는 순서를 권장합니다.

## 현재 기준 요약

- 게임은 Paper `1.21.11`, Java 21 기반입니다.
- 기본 구조는 최대 10명, 팀전은 2명 단위 팀 구성입니다.
- 게임 시작 전 참가자는 준비 상태이며, 팀은 수동 지정 또는 시작 시 랜덤 배정됩니다.
- 제단은 신호기 위에 팀 제단 아이템을 사용해 강제 설치합니다.
- 제단 설치 아이템은 핫바 4번 슬롯에 고정됩니다.
- 코인은 필드 드랍 코인만 획득 가능하고 버릴 수 없습니다.
- 상점은 F 키 또는 명령어를 통해 열며 필드에서 주운 코인으로만 구매합니다.
- 현상수배는 제단 3개 기준이 아니라 1등 팀의 리드 격차 기준입니다.
- 현상수배 기본 발동 격차는 `10.0%`, 해제 격차는 `7.0%`, 보상은 `8코인`입니다.
- 현상수배 리드 격차는 일반 플레이어 UI에 노출하지 않고 `/game 모니터링`에서만 보여줍니다.
- ItemsAdder 연동은 `model.yml`의 `itemsadder-id`와 `fallback-material`을 기준으로 합니다.
- 매치 통계는 `plugins/mayuela/stats/matches/` 아래 YAML로 저장됩니다.

## 인수인계 원칙

- 문서와 코드가 충돌하면 현재 코드를 먼저 확인합니다.
- 밸런스 관련 변경은 통계 저장 항목을 같이 늘립니다.
- Paper 서버 성능을 위해 매 tick 전체 스캔을 피하고, 기존 이벤트/스케줄러 주기를 활용합니다.
- 인벤토리, PDC, ItemsAdder, DisplayEntity, 스코어보드는 함께 움직이는 기능이므로 한 파일만 보고 판단하지 않습니다.
