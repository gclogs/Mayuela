# 운영 QA 체크리스트

이 문서는 Mayuela를 테스트 서버에서 검증하기 위한 체크리스트입니다.

## 테스트 단계

| 단계 | 목적 | 필요 인원 |
| --- | --- | --- |
| 컴파일 | Java 코드 연결 확인 | 0 |
| 서비스 단위 확인 | 순수 로직 검증 | 0 |
| 개인전 흐름 | 최소 플레이 흐름 확인 | 2 |
| 팀전 최소 | 팀전 기본 흐름 확인 | 4 |
| 밸런스 테스트 | 코인/현상수배/제단 속도 확인 | 4~10 |
| 운영 테스트 | reload, 강제 종료, 재접속 확인 | 1~10 |

## 0. 빌드 확인

```powershell
.\gradlew.bat compileJava
```

통과 기준:

- 컴파일 성공
- 새 deprecation 외 오류 없음

## 1. 서버 시작 전 파일 확인

확인 파일:

- `plugins/mayuela/game.yml`
- `plugins/mayuela/alter.yml`
- `plugins/mayuela/maps.yml`
- `plugins/mayuela/model.yml`

필수 설정:

```yaml
bounty:
  enabled: true
  warmup-seconds: 120
  min-leader-activation-percent: 20.0
  activate-gap-percent: 10.0
  release-gap-percent: 7.0
  transition-cooldown-seconds: 30
  reward-coins: 8
```

```yaml
system-items:
  field_coin:
    itemsadder-id: mayuela:field_coin
    fallback-material: GOLD_NUGGET
```

## 2. 운영자 명령어 기본 확인

명령:

```text
/game 모니터링
/game pdc
/game pdc 인벤토리
/game reload
```

확인:

- 권한 없는 플레이어는 관리자 명령을 사용할 수 없습니다.
- `/game 모니터링`에 게임 상태, 코인 상태, 현상수배 상태가 보입니다.
- `/game pdc`는 손 아이템 PDC를 보여줍니다.
- `/game reload` 후 설정 파일이 다시 로드됩니다.

## 3. 맵/스폰/제단 준비

명령 흐름:

```text
/game 맵 pos1
/game 맵 pos2
/game 맵 저장 test
/game 스폰등록
/game 제단등록 altar_1
/game 제단등록 altar_2
/game 제단등록 altar_3
/game 제단목록
```

통과 기준:

- 맵 저장 후 `maps.yml`에 위치가 기록됩니다.
- 스폰 등록 후 게임 시작 실패 사유에서 스폰 누락이 사라집니다.
- 제단 등록 후 `alter.yml`에 월드와 좌표가 기록됩니다.
- 제단 목록에 등록된 제단이 보입니다.

## 4. 시작 조건 실패 메시지

조건별 테스트:

- 참가자 없음
- 참가자 1명
- 팀전 홀수 인원
- 맵 없음
- 스폰 없음
- 제단 없음

통과 기준:

- “게임을 시작할 수 없습니다”만 나오지 않고 구체적인 사유가 출력됩니다.

## 5. READY 세션

흐름:

1. 플레이어가 `/입장`
2. 운영자가 `/game 팀전 시작`
3. READY 카운트다운 진입

통과 기준:

- 참가자는 준비 상태로 표시됩니다.
- 팀 색상은 시작 시 배정됩니다.
- 제단 아이템이 핫바 4번 슬롯에 있습니다.
- F 슬롯 아이템이 보조손에 있습니다.
- READY 중 아이템 드롭/설치가 차단됩니다.

## 6. PLAYING 기본 흐름

확인:

- 게임 스폰으로 이동합니다.
- 플레이어 머리 위 팀 색상 ItemDisplay가 따라다닙니다.
- 스코어보드 제목에 playtime이 표시됩니다.
- 보스바에 1등 팀 진행률과 점령 누적 시간이 표시됩니다.
- 코인이 필드에 드랍됩니다.
- 필드 코인에 glow와 `n초 뒤 제거됩니다.` TextDisplay가 보입니다.

## 7. 제단 설치

흐름:

1. 플레이어가 제단 아이템을 들고 신호기 우클릭
2. 신호기 위에 팀 제단 블록 설치
3. 모든 참가자에게 안내 메시지 출력

통과 기준:

- 신호기 GUI가 열리지 않습니다.
- 제단 블록이 강제로 설치됩니다.
- 제단 위 TextDisplay가 팀 이름/활성화율을 보여줍니다.
- 팀 아이템 lore의 점령 정보가 갱신됩니다.
- 스코어보드 진행률이 갱신됩니다.

## 8. 제단 파괴

흐름:

1. 상대 또는 본인 제단 블록 파괴
2. 제단 소유권 해제

통과 기준:

- 맨손으로도 파괴 가능합니다.
- 블록 드랍이 나오지 않습니다.
- 제단 TextDisplay가 빈 제단 표시로 바뀝니다.
- 전체 안내 메시지가 출력됩니다.
- 해당 팀 활성화율 상승 속도가 줄어듭니다.

## 9. 현상수배

준비:

- `game.yml`에서 필요하면 테스트용으로 워밍업과 최소 진행률을 낮춥니다.

확인:

- 1등과 2등 격차가 10% 이상이고 조건을 만족하면 현상수배가 발동됩니다.
- 일반 안내 메시지에는 리드 격차가 나오지 않습니다.
- `/game 모니터링`에는 리드 격차와 발동 가능 여부가 나옵니다.
- 현상수배 팀원은 glow 효과를 얻습니다.
- 머리 위 팀 ItemDisplay 아래에 `현상수배` TextDisplay가 보입니다.
- 현상수배 플레이어 처치 시 8코인을 받습니다.
- 같은 현상수배 플레이어를 다시 죽여도 추가 보상이 없습니다.
- 격차가 7% 이하가 되거나 1등이 바뀌면 해제됩니다.

## 10. 코인 경제

확인:

- 코인은 필드에서만 획득됩니다.
- 코인을 버릴 수 없습니다.
- 코인을 획득하면 인벤토리에 들어옵니다.
- 상점 구매 시 인벤토리 코인이 차감됩니다.
- 필드 코인만 추적됩니다.
- 만료된 코인은 엔티티와 TextDisplay가 같이 사라집니다.

모니터링:

```text
/game 모니터링
```

확인값:

- 필드 코인 수
- 적용 코인 룰
- 자동 제거 시간
- 플레이어별 앵커 선택 횟수
- 플레이어별 획득 횟수/코인량

## 11. 상점

확인:

- F 키로 상점이 열립니다.
- `/상점열기`도 정상 동작해야 합니다.
- `/은행열기` 요구사항이 실제 등록되어 있는지 확인합니다.
- 화살 1개 구매 가능
- 밀치기 막대기 구매 가능
- 점프강화 구매 가능
- 밀치기 저항 구매 가능
- 코인이 부족하면 구매 실패 메시지와 통계가 남습니다.
- 밀치기 막대기 보유 제한이 적용됩니다.

## 12. 전투와 부활

확인:

- 낙하 피해 없음
- 사망 시 아이템 드랍 없음
- 게임 스폰에서 부활
- 3초 이동 잠금
- 5초 무적
- 부활 후 이동속도 버프 복구
- 현상수배 표시 복구
- 갑옷 내구도 감소 없음
- 갑옷을 벗거나 갈아입을 수 없음
- 무적인 플레이어를 밀치기 막대기로 반복 타격하면 공격자에게 속박 적용

## 13. 재접속

상황:

- READY 중 접속 종료
- PLAYING 중 접속 종료
- 현상수배 상태에서 접속 종료
- 보스바 표시 중 재접속

통과 기준:

- PLAYING 중 나가도 팀/제단/진행률이 초기화되지 않습니다.
- 재접속 시 보스바와 스코어보드가 복구됩니다.
- 버프와 제단 아이템이 복구됩니다.
- 현상수배 glow/TextDisplay가 복구됩니다.

## 14. 게임 종료

확인:

- 승리 팀 안내
- 게임 플레이 타임 안내
- 팀별 코인 통계 안내
- 모든 팀 제단 블록 제거
- 필드 코인과 TextDisplay 제거
- 플레이어 DisplayEntity 제거
- BossBar 제거
- 인벤토리 초기화 또는 복구
- 참가자는 READY 상태
- `/퇴장` 입력 시 준비 취소

## 15. 통계 파일 확인

위치:

```text
plugins/mayuela/stats/matches/
```

확인:

- 매치 시작/종료 이벤트
- 코인 드랍/획득/만료 이벤트
- 제단 점령/파괴 이벤트
- 사망 이벤트
- 상점 구매 이벤트
- 현상수배 설정값
- 코인 설정값
- 참가자와 팀 정보

## 16. 회귀 테스트 목록

릴리즈 전 반드시 재확인:

- 신호기 GUI가 게임 중 열리지 않음
- 제단 아이템을 연타해도 중복 메시지가 과도하게 나오지 않음
- 게임 종료 후 갑옷이 이상하게 다시 입혀지지 않음
- 게임 도중 나갔다 들어와도 진행률이 초기화되지 않음
- 필드 코인 TextDisplay가 남아 떠다니지 않음
- 현상수배 보상이 중복 지급되지 않음
- `/game reload` 후 다음 게임 설정이 반영됨

## 17. 추천 테스트 순서

1. 컴파일
2. 1명으로 명령어/설정 실패 메시지 확인
3. 2명 개인전으로 제단/코인/상점/부활 확인
4. 4명 팀전으로 팀 구성과 현상수배 확인
5. 10명 또는 봇/스테이징 환경으로 코인 공평성 확인
6. 통계 파일 분석
